    运行层通过了什么

    同一逻辑位置仅保存一次成功回复；限流后按原请求恢复；预算没有重置。已完成目录再次启动，新增 API 请求为 0。独立审计可重建全部保存的请求。

    学生仍卡在哪里

    学生做了局部调整，但始终未满足实验操作顺序要求，最后自行选择 inconclusive。它仍剩 10 次请求预算；本轮没有进入候选发现验收，也没有触发 Reviewer。

    这是“有固定教材”的单次运行，不能据此推断教学收益。恢复的缓存回复只代表同一会话继续，不计为新样本。48 项相关测试通过，属于实现验证，不是模型成功率。

    已接入 · 本轮通过验收的发现为 0

    学习层：改进是否保持、旧能力是否退化

    只有完整且匹配的范围才能比较；需要重复锚点与持续运行，不能把恢复次数算学习次数。

    评估仍待积累 · 未建立保留或退化结论
    目前还没有的能力

    学生直接修改目标源码；对真实外部副作用的恰好一次执行与恢复；跨天长期保留的可靠结论；证明教学带来稳定收益。当前自动恢复只覆盖可从全新状态确定性重建的本地目标。

    “Hands off”具体意味着什么？

    运行前固定教材、规则、源码和上限。运行中学生自行选择下一步，宿主只返回预定义反馈；没有人工追加提示。运行后 Codex 对照账本和轨迹审计。宿主规则及审计仍是人设计的，所以不能把整个系统称为无人设计或完全自我改进。
