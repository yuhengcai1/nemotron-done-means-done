    What the runtime established

    Each logical position saved one successful reply. Rate-limit recovery retained the exact request and budget. Restarting the completed directory made zero new API requests. Independent audit reconstructed every saved request.

    Where the student remained stuck

    The student made local adjustments but never satisfied operation-order requirements, then chose inconclusive. Ten requests remained in its budget. No candidate reached finding verification or the Reviewer.

    This is one run with a fixed lesson, not evidence of teaching gain. Cached replies continue the same session and are not new samples. The 48 related tests passed as implementation checks, not a model success rate.

    05Long-term signals

    Identify the layer before evaluating improvement

    Transport: can requests complete?

    Actual attempts, 429s, unknown outcomes, and reported tokens. Unknown usage is not zero.

    Recorded · 14 requests / six 429s in this run

    Experiments: does feedback lead to valid revisions?

    Proposal validity, invalid-to-valid transitions, and duplicates; counted separately from API failures.

    Recorded · zero of five observed correction transitions

    Evidence: are conclusions supported?

    Reproductions and controls, unsupported claims, final state and event history, false completion and incomplete execution.

    Implemented · zero accepted findings in this run

    Learning: are gains retained without regression?

    Compare complete, matched scopes with repeated anchors and continued runs. Restarts are not learning events.

    Evidence pending · retention and regression not established
    Capabilities absent from this student experiment

    Direct target-source editing; exactly-once execution and recovery for real external effects; reliable cross-day retention conclusions; stable teaching gain. Automatic recovery here covers deterministic local targets reconstructible from fresh state.

    What does hands-off mean here?

    Lessons, rules, source, and limits were fixed before execution. The student chose its own actions; the host returned predefined feedback without additional human prompts. Codex audited the ledger and traces afterward. Host rules and audit were designed by people; this is not an entirely self-designed or fully self-improving system.
